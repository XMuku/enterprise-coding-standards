## 接入时记录

- 当前基线：未运行；需区分既有失败与本次问题。
- 失败样例：验证违规能导致失败，而非测试未命中源码。
- 修正样例：验证对应合法实现可以通过。
- 生成代码/构建产物排除：明确范围，不宽泛忽略业务代码。
- CI 状态：未接入；新增或修改 CI 以用户授权为准。
- 未验证项与原因：待实际执行后记录。
- 兼容性或规则例外：按项目记录，不全局关闭检查。

## 本次变更的验证计划（按需）

工具接入状态与本次结果分开。采用本项目已有风险分类；没有分类时参考已导出的 `quality-gates.md`（规范包内为 `references/quality-gates.md`）。小修复可直接在任务说明中记录，不必长期保存这张表。

- 验证对象/快照依据：待确认，不能只用分支名或未提交工作区的 HEAD。
- 风险档位与原因：待确认，综合行为、边界及规模，不只数行数。
- 接口契约唯一来源与生成方向：任务涉及 API 时确认。
- 敏感字段用途、允许流向与保护：任务涉及敏感数据时确认。
