# 将规范采用到一个项目

这里的项目必须由用户明确指定；Obsidian 是知识库，不因为保存了本包就成为业务应用。只请求会改变实施结果的缺失信息。

## 识别与确认

读取现有规则、真实构建文件和任务相关实现，记录适用的 JDK/Spring/容器、ORM、Vue/uni-app、HarmonyOS SDK/API、源码根目录、包管理器、目标平台和测试方式的证据。未知项标为待确认，不猜依赖版本，不强制生成全仓地图。

查明现有 AGENTS.override.md、AGENTS.md、CLAUDE.md 等入口与作用范围。只合并适用约束；不能覆盖用户已有规则或通过添加 override 文件绕过它们。

从所选专项的工程蓝图提取适用角色，在画像中填写真实目录、命名、依赖和注册/测试关联。已有项目用同类文件作为映射证据；新项目选择默认蓝图或明确调整。不因 controller 与 web 名称不同就启动迁移，不同时采用两种平行布局，也不为填表创建空层。

## 最小交付

| 文件 | 职责 |
| --- | --- |
| 项目规则入口 | 关键硬约束、按需读取入口和已确认的检查命令 |
| docs/coding-standards/project-profile.md | 技术栈、路径、术语、契约选择和实际命令；采用状态 |
| docs/coding-standards/common.md | 创建代码前的归属、命名与边界约束 |
| 通用专题 | 仓库结构、模块架构、命名与设计、测试、配置与日志、变更管理；按动作加载 |
| 适用技术栈规范 | 只保留真实使用的规范，不自动引入整个 Skill 仓库 |
| 数据访问规范 | 选择 Java/Spring 或 Java EE 时附带，涉及持久化才加载 |
| docs/coding-standards/checks-plan.md | 检查接入、基线、状态及未验证项 |
| sources.md / 例外记录 | 采用版本、来源和团队调整，不存凭证 |

模板为 [项目入口](../assets/agents-template.md)、[项目画像](../assets/project-profile-template.md) 和 [检查计划](../assets/checks-plan-template.md)。填写后删除无关选项；规则中的引用必须在目标项目内可解析，不能永久依赖个人 Obsidian 的绝对路径。

## 授权与状态

- “整理文档/准备模板”只授权文档，不意味着添加项目依赖、开启 CI 或迁移代码。
- “接入检查”时，按 [checks.md](checks.md) 选择兼容的工具版本、配置和测试；既有失败建立基线，不夹带整仓修复。
- 只有入口已合并、项目关键选择已确认且无模板残留时，才标记画像为“已采用”；检查状态仍逐项区分，不要求假装全通过。
- 选一个典型功能做写前走查：能定位入口、用例、数据边界及测试，能判定名字和依赖；只读走查不需要真的生成业务代码。工程蓝图确认不等于目录/依赖门禁已安装。
- 规则启用后先完成一个有代表性的安全任务，检查归属与命名是否在编码前生效，并验证构建及受影响测试。

## 可选的只准备工具

`scripts/prepare-project.mjs` 支持 --project 绝对路径、--stack 技术栈和 --apply。默认仅打印计划；明确 --apply 才导出本地规范、检查计划和 `AGENTS.md.candidate`，不写根 AGENTS.md、不安装依赖、不运行构建、不启用 CI。已有目标文件存在时整个导出拒绝覆盖。

例如选择 java-spring 或 uni-app；多个技术栈重复 --stack。可选值为 java-spring、java-ee、uni-app、miniprogram、harmonyos-arkui。导出不是采用完成；Agent 还要补齐画像并与现有规则合并。

所有选择导出通用专题，保证 common 及模板里的本地链接完整；只有选择 Java 技术栈才附带 data-access.md，避免纯前端项目混入服务端数据库规范。导出文件存在不代表每次都要加载。beta.2 比 beta.1 增加规则文件，旧项目先比较差异再合并，不重新加 --apply 覆盖已有目录。

工具需要 Node.js 22 或更高版本，使用系统核心模块，无 npm 安装步骤。导出画像包含所选技术栈的本地链接和包版本，但不推断源码目录或命令。路径检查会拒绝文件系统根、规范包自身、Obsidian 仓库及输出路径中的符号链接。导出前发现冲突不创建任何文件；执行中遇到权限错误或并发变更会停止并列出已创建的草稿，不自动删除或覆盖文件。这不是事务式安装器，也不提供抵御恶意并发文件系统替换的沙箱。
