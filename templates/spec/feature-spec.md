# 功能规格：填写任务名称

状态：草稿/已确认/实施中/待验证/完成（选择实际状态）。任务模式、范围和批准记录据实填写；本模板不授予编码、依赖安装、生产操作或发布权限。小功能可删去不适用栏目并写明原因，局部小改可用行内记录，不强制单建文件。

## 需求与边界

- 要解决的问题、用户可观察结果：待填写。
- 本次做什么/不做什么、允许与保护的相对路径：待填写。
- 已确认事实与来源、低风险假设、关键待确认项：待填写。
- 项目画像/采用规则/例外依据：待填写；未批准项不写成已同意。
- 风险：low/standard/high，依据既有 quality-gates.md；看语义影响，不只看行数。

## 写前设计

首次相关源码写入前完成适用项；修改设计保留原因，不事后伪造写前记录。

| 对象 | 真实相对路径与名称 | 职责与允许/禁止依赖 | 注册/测试/消费者证据 |
| --- | --- | --- | --- |
| HTTP 入口或其他适配层 | 待填写或复用 | 协议边界，不写 SQL | 待填写 |
| 用例服务 | 待填写或复用 | 业务流程；实际事务模型 | 待填写 |
| 持久层（确需时） | 待填写或不适用 | 按既有 Mapper/Repository/端口 | 待填写 |
| DTO/模型/接口/基类 | 待填写或不需要 | 为什么需要抽象/继承；优先组合 | 待填写 |
| 测试 | 待填写真实发现位置 | 正常、拒绝与失败断言 | 待填写执行配置 |

Java 包全小写、类型 PascalCase、方法/字段 camelCase、常量 UPPER_SNAKE_CASE 是默认；正式项目约定和已批准例外按原规范处理。接口层不等于必建 interface，模板不授权另建一套目录。

## 接口、字段与数据契约

| 项目 | 要记录的决定 |
| --- | --- |
| 唯一契约来源 | 代码优先或 schema 优先；生成物不手改 |
| API | 方法/路径/版本、输入允许集、响应/错误、分页与旧消费者 |
| 字段 | 名称、业务含义、类型/精度、单位/时区、缺失/null、范围/默认、敏感性与兼容 |
| 身份与授权 | 可信身份入口、对象/租户归属判断、拒绝行为；不信任客户端 userId |
| 数据变化 | 查询参数化/动态标识符允许列表、约束/并发、事务/回滚与迁移边界 |
| 外部副作用 | 超时、幂等/重试预算、隔离环境、费用与清理范围 |

不需要的项据实说明。没有需求不增加审计/逻辑删除/租户字段，不默认 BigDecimal 以外的特定存储方式，不猜数据库或框架版本。

## 实施与协作

1. 先确认契约/失败路径和回归位置，再实现最小可验证路径。
2. 同步必要注册、映射、配置、文档和测试，不夹带框架升级/整仓格式化。
3. 发现范围、风险或消费者变化时更新计划并保留原因；关键未知阻断相关动作。

单 Agent 默认。确需多 Agent 时记录任务依赖、每人不重叠写入路径、公共契约负责人、产物快照和集成顺序；复用 [交接模板](agent-handoff.md)，角色名称不提供权限隔离。

## 意图复核与交付

逐项对照 AC：已实现、部分实现、缺失、矛盾或范围外行为；记录证据，不只勾选完成框。未验证、失败、例外和兼容风险保持可见。提交建议按团队约定，PR 包含目的、变化、实际检查与缺口；不自动提交、推送或部署。
