# MCP 高级可选扩展

默认不启用。MCP 是宿主与工具/资源的协议，不是 Java 编码规则或测试门禁。基础入口、spec 和企业标准采用不依赖 MCP。本次只有参考文档，没有服务器配置、SDK、安装器或凭证。

研读来源见 [MCP 固定快照卡片](../research/06-mcp.md)。该快照含 `2026-07-28` 规范目录与许可证过渡；接入时重新确认实际宿主、SDK、协议日期/能力及具体文件许可，不假设全生态支持同一版本。

## 接入前记录

| 项目 | 必须有的真实决定 |
| --- | --- |
| 必要性 | 哪个已授权任务缺少本地能力；不用外部服务的替代方案 |
| 来源/版本 | 服务/实现来源、所选协议、能力与兼容验证 |
| 身份/权限 | TLS/认证、令牌受众/范围、逐客户端同意、最小允许操作 |
| 数据 | 可以发送的字段、分类/脱敏、目的、保存与删除政策，不转发完整聊天/仓库/生产数据 |
| 操作边界 | 只读/写入、确认条件、超时/重试/成本、网络与 SSRF 防护 |
| 返回处理 | schema/来源/内容校验；描述和注解不是可信指令或授权 |
| 证据/退出 | 隔离环境、成功/拒绝/失败验证，日志脱敏、撤销/停用与清理责任 |

不透传为其他服务签发的令牌，不因工具名或能力声明扩大范围。禁止让未审查服务得到生产写权限或执行远端返回的命令。工具调用成功不代表 Java 变更通过验收，仍按既有风险与测试证据交付。

上述是评审清单，不是运行时实现或安全认证。任何安装、联网、费用、数据外发和写操作需当前任务明确授权；默认不开启，不将缺少 MCP 记为基础编码阻断。
