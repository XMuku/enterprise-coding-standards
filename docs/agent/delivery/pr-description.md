# PR 标题

docs(agent): add enterprise pre-code adapters and spec templates

## 目的

在现有企业编码标准上新增轻量 Agent 采用层，让写代码前的目录、命名、分层、接口/字段、安全与验证决定有明确入口；优先支持 Java 后端，不替换既有五类专项或项目架构。

## 新增内容

- 八个项目的固定快照分析卡片、能力矩阵和 27 项取舍/发布记录，区分规则、工作流、工具与通信协议。
- Cursor、Aider、Copilot、Claude Code 原生薄入口，以及供业务项目差异采用的独立候选模板。
- 共享写前执行契约、功能/修复 spec、多 Agent 交接与两份已填写 Java 文档走查。
- 启用指南、兼容边界、默认关闭的 MCP/A2A 参考、完整变更清单和验证记录。
- 12 项行为验收用例与四种宿主证据要求；Spring/Java EE 离线草稿组装及拒绝覆盖实测。
- README 末尾导航、常见启用问题排查和 Claude 会话/上下文兼容边界。

## 使用方式

维护规范包从根原生入口读取现有 AGENTS 与共享契约；Java 业务项目先确认本地画像/规范，再合并业务模板。Aider 用 read 配置，.aider.rules 本身不自动加载；Copilot 链接不自动导入；Claude 保留原生导入以适配版本/设置差异。小任务可行内记录，不强制长规格或多 Agent。

## 兼容与保护

本次新增 39 个文本/配置文件，并在根 AGENTS 与 README 末尾追加扩展入口/导航，全部原文保留。其余 121 个既有文件不变，不改已有规范正文、版本、代码、依赖、脚本或 CI，不移动删除文件。高级协议不进入基础强制规则，不部署运行时。来源只作原创提炼与链接，不复制适配器实现；保持本包无 LICENSE 的现有决定。

根 AGENTS 继续是规范包维护入口，不是业务项目模板；追加段要求首次写入前读取共享契约。候选文件只保留为已批准内容的追溯记录，不重复加载。四种新增入口直接引用共享契约。README 导航已追加，原文未覆盖。
