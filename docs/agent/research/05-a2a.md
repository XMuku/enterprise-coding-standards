## 工作流与亮点

发现并核对 Agent 能力和认证要求，发送消息；长期工作用任务追踪、流式或异步更新。任务终态与业务验收不同；后续修订需要清晰产物版本。协议帮助跨系统互操作，不等于已运行安全审查或企业测试。

## 局限与适配

引入 SDK、远端身份、任务状态、回调和运维显著扩大攻击面。版本和绑定不能只按 README 中 JSON-RPC 示例推断；需要核对所选协议与 SDK。远端产物可能含提示注入、秘密或未经核验的成功声明。

| 判断 | 取舍与原因 |
| --- | --- |
| 保留 | 仅在可选扩展中说明版本、身份、范围、产物与状态校验 |
| 调整 | 协议 completed 只说明远端任务终态；仍按本包证据要求验收 Java 变更 |
| 不引入 | 基础规则中的 A2A 服务/SDK/注册表/自动委托、直接转发凭证或生产资料 |
| 适用 | 已有跨团队远端 Agent 且明确需要互操作的高级采用任务 |
| 不适用 | 单个本地编码 Agent、纯规范加载、代码命名或测试门禁 |
