## 剩余验证边界与风险

维护者于 2026-10-03 授权“仅追加”，根 AGENTS 已追加共享契约入口，原维护内容保留；候选文件只作追溯记录。根入口选择不再是未完成项，原文保留与追加范围检查仍须作为独立证据；不能将这项检查当作四种宿主的实际加载证明。

规则加载受工具版本、设置、功能、启动目录和上下文影响；文本不保证遵守或提供沙箱。Copilot 链接不是 import，Aider .aider.rules 需 read，Claude/AGENTS 直接加载有版本和设置条件。工具实际验收按 [启用指南](01-enable-guide.md) 执行。

Java 案例只验证模板覆盖与内部一致性：功能案例没有实施，修复案例明确虚构回归，不能据此声称业务测试红绿通过。现有导出器不包含新文件，业务采用需手工差异合并并补齐真实画像/命令。

MCP/A2A 默认关闭，没有 SDK/服务/凭证；无互操作验收。未来只在独立任务授权后验证协议、身份、数据、费用、失败/撤销与真实门禁，不把通信协议加入基础强制规则。

## 可重现的后续验收

1. 核对根入口只有批准的末尾追加、全部原文保留，变更后重跑规范包检查和隐私/差异检查。
2. 在实际所用宿主确认工具版本与入口加载、有效配置和只读规则路径；使用 [12 项行为验收用例](06-acceptance-cases.md) 分别记录加载、行为与应用检查状态。
3. 执行只读写前走查，确认无文件变化，再在授权代表性任务中核对决定出现在首次源码写入之前。
4. 用项目真实命令验证非空覆盖与拒绝/失败路径，保留差异、快照、命令/数量/退出码和未执行项，不借过去 CI 冒充新结果。
5. 业务采用更新按差异合并；未来版本发布、导出器升级和远端 PR 仍是独立任务。本次已明确授权文档增量推送，不提升版本、不创建 Release/标签、不部署业务应用。
