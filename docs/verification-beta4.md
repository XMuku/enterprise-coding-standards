# 1.2.0-beta.4 文档与回归验证

日期：2026-10-02。本文记录本次流程、提示词、模板、导航与许可状态更新的验证，不替代业务项目验收。

## 改动范围

- 新增十阶段完整流程与 12 类任务提示词，明确首次写入前的目录、命名、接口/继承、字段、契约和验证决定。
- 新增可选任务记录与交接模板；导出文件集合不变，不自动附带 prompts、流程手册或这两份模板。
- 精简 Skill、common 与项目入口补充执行顺序；发布文档改为维护者已决定不添加 LICENSE。
- 校验器增加新分发文件要求，并加入缺失流程/提示词/模板时拒绝的回归测试。
- 未修改示例源码、示例依赖、CI 工作流、评分器及独立验收实现。

## 当前验证

命令在规范仓库根目录执行，结果只覆盖当时执行环境；机器定位与完整环境指纹不随发行分发。

| --- | --- | --- |
| `npm run check` | 退出 0；108 个分发文件、53 个 Markdown 文件校验无错误；35 项测试通过，0 失败/跳过 | 版本、结构、本地文件链接、已有敏感内容启发式检查、导出与评测工具回归 |

## 未验证与历史证据

本轮没有重新运行示例构建、示例反例、独立 Agent 行为评测、微信开发者工具/真机、远端 CI 或生产业务项目。历史示例与评测的结果、依赖风险和中断情况见 [beta.3 记录](verification-beta3.md)，不将历史结果改写为 beta.4 全流程通过。

尤其是 beta.3 记录的 uni-app 审计 40 个受影响依赖项（13 高、12 中、15 低），本轮未升级依赖也未重新审计，风险未被本次文档工作解决。正式采用或发布时应重新核查，不能称风险已消除或当作实时审计数量。

提示词仍需要分别在代表性项目中做现实任务验证；文件存在、链接正确、基础 Skill 校验成功，不证明任何 Agent 已在首次写入前作出正确决定，也不证明所有技术栈、模型或企业合规要求均被覆盖。
