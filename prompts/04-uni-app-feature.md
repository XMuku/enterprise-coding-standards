```text

核对实际 uni-app/uni-app x、Vue、语言、CLI/HBuilderX 工程形态、构建脚本与包管理器。
找到页面注册、组件、composable/store、API 服务、类型、资源和测试的实际目录。
读取相关调用者及接口契约，保留用户修改，不新增无用通用目录或切换 UI 库。

首次写入前说明：
1. 页面/组件/服务/类型的真实路径和命名，现有路由及注册位置。
2. 组件 props、事件、可空性与状态归属；局部状态不无故提升为全局 store。
3. API 参数/响应类型、错误、分页、身份处理，字段单位与后端对应关系。
4. 加载、空、成功、失败、重试、禁用/重复点击等实际需要的状态。

实施要求：
- 遵从实际 Vue 版本的数据流和生命周期，不直接修改 props；复用既有请求/错误机制。
- 网络边界验证不可信数据，不用 any 或不实类型断言掩盖契约错误。
- 页面请求参数变化时避免旧响应覆盖新结果；离开或卸载时处理资源生命周期。
- 列表 key 稳定，分页/筛选/排序语义明确，空态不与网络故障混为一谈。
- 不假设所有目标端存在 window/document/localStorage 等浏览器能力。
- 平台特有逻辑采用项目已有隔离方式，不能为了编译排除整块业务源码。
- 路由、资源路径和导入大小写一致；不手工编辑 dist/unpackage 或生成平台代码。
- 不把服务端密钥放进客户端环境变量；前端隐藏按钮不等于后端授权完成。

H5 构建、H5 浏览器操作、微信构建、微信开发者工具、真机分别报告。
```
